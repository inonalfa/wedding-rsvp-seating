# Contributing

Issues and pull requests are welcome. Discuss large changes in an issue first. Keep examples fictional; never attach real guest exports, invitation links, webhook endpoints, credentials or D1 files.

Follow README setup. Run `npm run typecheck`, `npm run lint` and `npm test`. Add focused regression tests for token validation, guest matching, seat capacity, revision checks, authorization, migrations and webhook retries. Do not edit an applied migration; add a new one. Preserve Hebrew RTL, keyboard access and mobile layout.

Report security issues privately as described in SECURITY.md.
